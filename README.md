# Portfolio Website

This is a simple portfolio website built using pure HTML, CSS, and JavaScript. It includes sections for a blog, projects, an about page, and a contact page.

## Project Structure

```
portfolio-website
├── index.html          # Main entry point of the portfolio website
├── css
│   ├── style.css      # Main styles for the website
│   ├── blog.css       # Styles specific to the blog section
│   └── projects.css    # Styles specific to the projects section
├── js
│   ├── main.js        # Main JavaScript functionality
│   ├── blog.js        # JavaScript for managing the blog section
│   └── projects.js    # JavaScript for managing the projects section
├── blog
│   ├── index.html     # Main page for the blog section
│   ├── posts
│   │   ├── post-template.html  # Template for creating new blog posts
│   │   └── post1.html          # Example blog post
├── projects
│   ├── index.html     # Main page for the projects section
│   └── project-template.html    # Template for creating new project entries
├── about
│   └── index.html     # Information about the website owner
├── contact
│   └── index.html     # Contact form or information
├── assets
│   ├── fonts          # Directory for font files
│   └── icons          # Directory for icon files
└── README.md          # Documentation for the project
```

## Features

- **Blog Section**: Easily create and manage blog posts with a dedicated section.
- **Projects Section**: Showcase your projects with individual project pages.
- **About Page**: Provide information about yourself and your skills.
- **Contact Page**: Allow users to reach out through a contact form or information.

## Getting Started

1. Clone the repository or download the files.
2. Open `index.html` in your web browser to view the portfolio.
3. Customize the content in the `blog` and `projects` directories to add your own posts and projects.
